# Research project links

This GitHub Pages repository serves the [research project index](https://alexw4123.github.io/) and preserves older project bookmarks.

| Page | Canonical site | Source repository |
| --- | --- | --- |
| Heme research | [Open Heme](https://alexw4123.github.io/heme/) | [heme](https://github.com/alexw4123/heme) |
| DHFR research | [Open DHFR](https://alexw4123.github.io/dhfr/) | [dhfr](https://github.com/alexw4123/dhfr) |

- `index.html` is the landing page.
- `guanosine-heme-cinematic-viewer/index.html` redirects old Heme bookmarks to `/heme/`.
- `dhfr-cinematic-viewer/index.html` redirects old DHFR bookmarks to `/dhfr/`.

Both redirects preserve the original query string and fragment. The project sites deploy from their own repositories. This repository requires no dependency install or build step.
